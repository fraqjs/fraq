欢迎来到 Fraq 的文档！Fraq 是一个 Milky 协议下的 TypeScript 聊天机器人框架。Milky 是基于 HTTP / WebSocket 通信的 QQ 机器人应用接口标准。你可以随时通过 [Milky 的官方网站](https://milky.ntqqrev.org/)来了解更多关于 Milky 的信息。

Fraq 需要在 **Node.js 22+** 环境（或其他支持 WebSocket API 的服务端 JS 环境）中运行。
