`@fraqjs/plugin-cli-integration` 提供了通过 WebUI 管理 Fraq CLI 的能力。

## 安装与配置

将插件添加到 `fraq.yml` 的 `plugins` 字段下：

```yaml
plugins:
  # 本插件依赖 fraqjs/hono 和 fraqjs/webui-gateway，因此需要一并安装
  fraqjs/hono:
    # 在这里传入 HonoPlugin 的配置选项
  fraqjs/webui-gateway:
    # 在这里传入 WebuiGatewayPlugin 的配置选项
  fraqjs/cli-integration:
```

插件开发者通常情况下无需直接使用 `CliIntegrationPlugin`。本插件仅在使用 `fraq start --watch` 时有效。
