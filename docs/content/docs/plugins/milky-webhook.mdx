`@fraqjs/plugin-milky-webhook` 提供了将 Fraq 接入 Milky 协议端 Webhook 事件推送的能力。

## 安装与配置

将插件添加到 `fraq.yml` 的 `plugins` 字段下：

```yaml
plugins:
  # 本插件依赖 fraqjs/hono，因此需要一并安装
  fraqjs/hono:
    # 在这里传入 HonoPlugin 的配置选项
  fraqjs/milky-webhook:
    # Webhook 事件推送的接收端点，默认值为 /milky/webhook
    endpoint: /milky/webhook
    # Milky Webhook 的访问令牌，用于验证请求的合法性
    # 默认不进行验证，请务必在生产环境中设置一个安全的访问令牌
    accessToken: 'my-secret-token'
```

插件开发者通常情况下无需直接使用 `MilkyWebhookPlugin`。
