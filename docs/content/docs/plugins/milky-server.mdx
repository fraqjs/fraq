`@fraqjs/plugin-milky-server` 提供了在 Fraq 上代理上游 Milky 服务的能力。

## 安装与配置

将插件添加至 `dependencies`，然后在创建 `Context` 时引入并配置插件。本插件依赖 [`@fraqjs/plugin-hono`](./hono.mdx) 插件，因此需要一并安装。

```typescript
import HonoPlugin from '@fraqjs/plugin-hono';
import MilkyServerPlugin from '@fraqjs/plugin-milky-server';

ctx.install(HonoPlugin, {
  // 在这里传入 HonoPlugin 的配置选项
});
ctx.install(MilkyServerPlugin, {
  // 在这里传入 MilkyServerPlugin 的配置选项
});
```

`MilkyServerPlugin` 有如下配置项：

- `accessToken`：Milky 协议的访问令牌，用于验证 `/api` 和 `/event` 请求的 `Authorization` 头。默认为 `undefined`，即不进行验证。请务必在生产环境中设置一个安全的访问令牌。
- `prefix`：端点的路径前缀。默认为 `/milky`，即端点为 `/milky/api/:api` 和 `/milky/event`。

插件开发者通常情况下无需直接使用 `MilkyServerPlugin`。

## 端点说明

插件注册的端点遵循 [Milky 通信协议](https://milky.ntqqrev.org/guide/communication)：

- `POST {prefix}/api/:api`：API 调用端点。请求体以 JSON 传递参数，响应格式为 `{ status, retcode, data | message }`。
- `GET {prefix}/event`：事件推送端点。根据请求的 `Upgrade` 头自动选择 WebSocket 或 SSE 连接，连接建立后将上下文接收到的事件实时推送给客户端。
